🚀 1. Qual tecnologia escolher? (2 Caminhos)

Opção A: Unity + AR Foundation (Recomendado)

Ideal para visual 3D estilo "desenho/cartoon" (Toon Shaders), animações orgânicas de batimento/respiração e detecção de imagens (marcadores impressos em apostilas).

Opção B: Kotlin Nativo + Sceneview (ARCore)

Usa Jetpack Compose para a interface e a biblioteca io.github.sceneview:arsceneview para renderizar arquivos .glb em RA com ótimo desempenho.

🎨 2. Como criar os Órgãos em 3D "Estilo Desenho Amigável"?

  • Modelagem (Blender): Use formas arredondadas (Subdivision Surface) sem texturas médicas realistas/sangrentas. Prefira cores vibrantes e pastéis (como neste protótipo).
  • Toon Shader / Cel Shading: Aplique um material de sombreamento em 2 ou 3 tons com contorno escuro fino (Outline) para parecer uma ilustração 2D viva em 3D.
  • Exportação glTF / GLB: Separe cada subparte do órgão como um nó nomeado (ex: Aorta_Mesh, Ventriculo_Esq_Mesh) para detectar o toque individual (Raycasting).

📲 3. Fluxo de Interação em Sala de Aula (Marcador vs Superfície)

Com o ARCore Augmented Images, você pode criar cartões impressos (Flashcards de Anatomia). Quando o aluno aponta a câmera para o cartão do Coração, o modelo 3D salta da folha! Caso não tenha o cartão, o Plane Detection posiciona o órgão sobre a carteira escolar.
